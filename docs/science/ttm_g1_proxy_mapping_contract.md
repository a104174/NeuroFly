## Observation references and unchanged blockers

The domain references all nine canonical Phase 8S IDs, partitioned as follows:

- Seven G1-domain observations: resting, evoked, miniature, quantal content,
  spontaneous frequency, categorical repeated response and recycling rate.
- The prior equilibrium analysis input has a separate **analysis-context**
  reference, not a direct validation target or reversal parameter.
- The Kadas composite latency has a separate **system-boundary** reference,
  not an intracellular G1 observation or isolated NMJ delay.

Only IDs are stored. Values, units, protocols, classifications and uncertainty
are not copied. Phase 8S remains their sole authority. The seven-record group
means domain relevance, not that all are measured directly or comparable to
an evoked-only electrical model. Phase 8U remains authoritative for each
comparison role, operator status, protocol requirement and blocker; none is
duplicated or overridden here.

Domain selection resolves only the explicit reduced-domain assumption.
Physical input transformation, model quantities, operators, protocol matching,
release/spontaneous/history/vesicle semantics and the Kadas system boundary
remain unresolved. Formal-ready Phase 8U mappings remain **zero**. The Phase
8X decision snapshot is architecture metadata, not physiological evidence.

## Model neutrality and explicit exclusions

The contract selects no phenomenological, passive-membrane, conductance or
quantal model. A later adapter could qualify a Phase 8W causal context with
this domain, but no such adapter exists here. Model-specific transformation
parameters belong in a separate, identified future configuration.

Persisted exclusions prohibit exact MaleCNS-to-G1 tracing, exact peripheral
endpoints, a shared physical G1 instance, side-resolved physiology, bilateral
equivalence, identical physiology across fibers, whole-TTM representation,
observations as model parameters, successful transmission claims, physical
input transformation, runtime instances/events, dynamics, executable operators,
comparison/calibration/acceptance windows, contraction/force/mechanics/behavior,
production composition and DLM work.
