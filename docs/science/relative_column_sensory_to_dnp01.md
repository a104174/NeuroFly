# Phase 7F — bounded exploratory sensory-to-DNp01 transfer

Phase 7F establishes a reproducible **model** boundary from the four Phase 7E
dimensionless sensory states to the two existing DNp01 LIF model neurons. It
does not calibrate LC4/LPLC2→DNp01 physiology. The reference output contains
no simulated DNp01 spikes, which is a valid result rather than a parameter
selection failure.

## Transfer and time semantics

Model identity: `exploratory_edge_routed_model_drive_v1`; configuration/result
schemas: `relative_column_sensory_to_dnp01_config_v1` and
`relative_column_sensory_to_dnp01_result_v1`. For each routed source `i`,

```text
d_i[n] = k_transfer_mveq_per_state × x_i[n]
D_target[n] = sum of d_i[n] over unmasked sources routed to target
```

`x_i` is a dimensionless *exploratory* Phase 7E state. `d_i` and `D_target`
are voltage-equivalent model drives (`mV_eq`), not currents, conductances,
EPSPs, or synaptic efficacy. The shared positive reference conversion
`k_transfer_mveq_per_state = 1.0` is a `MODEL_ASSUMPTION`, selected for a
simple, numerically safe software reference, not tuned to biological data or
the earlier angular-looming spike times. It is identical for all four edges;
there is no LC4/LPLC2 or L/R hidden gain. Contributions sum without
normalization. No old angular `theta_rad`, type-level `lc4_drive_mveq`, or
`lplc2_drive_mveq` participates.

Phase 7E `x[n]` is a stored **boundary** state at `n × dt_ms` (`dt_ms=0.1` in
the fixed source). It drives DNp01 on interval `[n,n+1)`; the LIF state and
any simulated spike generated by that interval are recorded at boundary
`n+1`. Thus Phase 7D exposure interval `n` creates sensory state `x[n+1]`,
which first enters DNp01 during interval `n+1`. This is an explicit causal
sample/update convention, not a measured biological transmission delay.
Integer steps are authoritative; displayed time is `step × dt_ms`.

The existing `LIFSimulator` equations, rest/reset/threshold, time constants,
refractory rule, and spike semantics are unchanged. A provenance-gated
Phase 7F input mode permits model drive **only** to DNp01 body IDs 10001 and
10010 in the separate two-readout graph; ordinary DNp01 external drive and
Phase 7F drive in the established 313-node graph remain rejected. The two
readouts retain their exact source identity and the graph has **zero event
edges**, so no structural-weight-scaled event can be delivered. The required
`k_syn_mv_per_contact=0.01` config field is dormant in this experiment and is
not the Phase 7F transfer coefficient. Filtered synaptic state remains zero.
No DNp01 output is forwarded to TTMn.

## Controls, sensitivity, and real result

The reference pairs the Phase 7E left/right expanding relative-column
conditions as independent simultaneous model inputs. This is **not** a
physical bilateral optical registration. Additional runs use `k=0`, no
sources, LC4-only, LPLC2-only, the left LPLC2-centred disk, and right
translated disk. The fixed non-optimized sensitivity grid is `k = 0, 0.5,
1, 2, 4 mV_eq/state`.

For the reference `k=1`, DNp01 10001 R receives LC4 16128 and LPLC2 14465:
peak drive `0.2320754340 mV_eq` at input interval step 4 (`0.4 ms`), and
membrane range `-52.0` to `-51.9914988616 mV`. DNp01 10010 L receives LC4
12032 and LPLC2 11498: peak drive `0.1238398218 mV_eq` at step 4, and
membrane range `-52.0` to `-51.9954742466 mV`. Both filtered states remain
zero; neither body spikes. `k=0` and no-source controls have zero drive and
remain at `-52.0 mV`. LC4-only/LPLC2-only contributions add to the combined
model drive; the left LPLC2 disk affects only DNp01 L and the right translated
disk only DNp01 R. At `k=0.5/2/4`, drive scales linearly and the maximum
DNp01 R membrane is approximately `-51.99574943/-51.98299772/-51.96599545
mV`; no sensitivity run spikes. This characterizes software causality, not
biological tuning.

## Scientific boundary and next question

**MaleCNS source:** six body identities, four chemical routes, structural
contact counts. **Exploratory source model:** four Phase 7E dimensionless
states from synthetic relative-column anatomical exposure. **Phase 7F model
assumption:** positive shared conversion to `mV_eq`, pathway masks, and
simultaneous independent L/R test conditions. **Existing model:** DNp01
point-neuron LIF state/spikes. **Unknown:** individual functional RFs, visual
angles, response gains, sign/efficacy per synapse, true neuronal transfer,
and biological calibration. No behavior, muscle, motor propagation, or
313-neuron dynamics is established. A bounded Phase 7G should assess this
four-body transfer's sensitivity/evidence gap before any 311-body scaling.
