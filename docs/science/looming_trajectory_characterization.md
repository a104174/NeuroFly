# Phase 2F — looming trajectory characterization

## Scope and scientific status

Phase 2F characterizes the complete deterministic production path:

```text
LoomingStimulus
  -> aligned pre-collision LoomingSample values
  -> level_p_instantaneous_bounded_v1
  -> ExternalDriveSchedule
  -> Phase 2B 313-node / 311-edge LIF graph
  -> separate DNp01 10001 and 10010 telemetry
```

All numeric encoder and coupling values below are
`NEUROFLY_SYNTHETIC_BENCHMARK`. They are explicit operating-regime probes,
not biological estimates, calibrated defaults, or production recommendations.
No value was fitted to Giant Fiber latency or another experimental response.

The implementation is `neurofly.trajectory_characterization`. It constructs
no alternative stimulus, encoder, graph, or simulator. Results are immutable,
in-memory summaries with deterministic configuration and result SHA-256
identities. No result artifact is generated by default.

## Benchmark contract

`LoomingTrajectoryScenario` combines one production `LoomingStimulus` with an
explicit duration. `sample_looming_trajectory` samples `[0, duration)` exactly
on neural-step boundaries and rejects grids that do not divide the duration or
that produce a collision sample.

`TrajectoryBenchmarkPoint` requires an explicit E1 encoder configuration,
`k_syn_mv_per_contact`, `dt_ms`, and one pathway condition:

- `ZERO`: both encoded pathways are masked;
- `LC4_ONLY`: only LC4 schedule values remain;
- `LPLC2_ONLY`: only LPLC2 schedule values remain;
- `COMBINED`: the unmodified production E1 output is used.

Masking changes only caller-supplied external drive. It does not mutate or
retarget any biological edge. All 313 nodes and the exact 311 active direct
visual-to-DNp01 edges remain present. DNp01 is never a schedule target.

The compact result preserves stimulus geometry, full normalized-feature and
applied-drive traces, visual-population spike summaries, per-DNp01 state and
event summaries, simulator-relative timing, replay status, graph/model IDs,
and synthetic provenance.

## Synthetic reference configuration

The declared `SYNTHETIC_REFERENCE_CONFIGURATION` used for the principal
tables is:

| Quantity | Value | Status |
| --- | ---: | --- |
| `G_LC4` | 20 `mV_eq` | synthetic encoder gain |
| `G_LPLC2` | 20 `mV_eq` | synthetic encoder gain |
| `omega_half` | 1 rad/s | synthetic normalization scale |
| `theta_half` | 0.4 rad | synthetic normalization scale |
| `k_syn` | 0.005 `mV_eq/contact` | synthetic model coupling |
| neural `dt` | 0.1 ms | numerical benchmark choice |

These values are passed explicitly. They are not defaults in either
`LevelPEncoderConfig` or `LIFConfig`.

The bounded one-at-a-time probes were:

- `G_LC4`: 10, 20, 40 `mV_eq`;
- `G_LPLC2`: 10, 20, 40 `mV_eq`;
- `omega_half`: 0.5, 1, 2 rad/s;
- `theta_half`: 0.2, 0.4, 0.8 rad;
- `k_syn`: 0.001, 0.005, 0.01 `mV_eq/contact`;
- descriptive regime probes: equal gains 5 with `k_syn=0.001`, equal gains 10
  with `k_syn=0.001`, and equal gains 50 with `k_syn=0.0015`;
- timestep probe: 0.05, 0.1, and 0.2 ms at the reference parameters.

The one-at-a-time set is intentionally small and is not an optimizer or a fit.

## Trajectory family and stimulus geometry

All principal trajectories use radius 0.01 m, initial distance 0.1 m, and
center `(0, 0)` radians. Only approach velocity changes. Each run stops at 80%
of collision time; terminal collision is never sampled.

| --- | ---: | ---: | ---: | ---: | ---: |

## Encoder behavior

Both E1 channels are nonzero at the first approaching sample. The reference
configuration gives:

| Trajectory | LC4 peak normalized / drive | LC4 headroom to 1 | LPLC2 peak normalized / drive | LPLC2 headroom to 1 |
| --- | ---: | ---: | ---: | ---: |
| slow | 0.952199 / 19.043987 | 0.047801 | 0.698181 / 13.963627 | 0.301819 |
| reference | 0.975419 / 19.508379 | 0.024581 | 0.697728 / 13.954559 | 0.302272 |
| fast | 0.987458 / 19.749166 | 0.012542 | 0.696822 / 13.936448 | 0.303178 |

LC4's velocity normalization is close to its mathematical upper bound late in
all three windows, so doubling already-large expansion velocity changes drive
only weakly. LPLC2 remains farther from the bound. This is saturation of the
chosen normalization formula, not measured neuronal saturation.

Static (`velocity=0`) and receding (`velocity=-1 m/s`) controls produced zero
LC4 and LPLC2 drive, no spikes, and regime R0, exactly as the versioned E1
clamp/gate specifies. This is a model policy, not a claim of zero biological
response. Motion-free darkening and wide-field translation remain unsupported
because the current scalar Level P vocabulary cannot represent them.

## Operating regimes

Phase 2F uses descriptive NeuroFly benchmark labels only:

- R0: no visual spikes;
- R1: visual spikes with both DNp01 bodies subthreshold;
- R2: exactly one DNp01 body reaches threshold;
- R3: both DNp01 bodies reach threshold once;
- R4: at least one DNp01 body spikes repeatedly.

These are not escape or behavioral states. The small regime probes reached R0
(gains 5, `k_syn=0.001`), R1 (gains 10, `k_syn=0.001`), R2 (gains 50,
`k_syn=0.0015`), and R4 (the reference configuration). R3 is defined and
tested as a classification boundary but was not forced by tuning a fixture.

| Trajectory | LC4 spikes / first (ms) | LPLC2 spikes / first (ms) | DNp01 10001 spikes / first | DNp01 10010 spikes / first | Regime |
| --- | ---: | ---: | ---: | ---: | --- |
| slow | 1,260 / 21.6 | 925 / 51.8 | 2 / 121.2 ms | 4 / 64.9 ms | R4 |
| reference | 756 / 13.9 | 370 / 40.0 | 1 / 69.3 ms | 2 / 45.3 ms | R4 |
| fast | 378 / 10.9 | 185 / 30.1 | 0 / none | 1 / 36.6 ms | R2 |

Because the observation window scales with collision time, the faster case has
less physical time in which to accumulate repeated spikes. A higher velocity
therefore does not imply more spikes under this fixture. Within each visual
type all bodies have the same first-spike time: this follows from bilateral
E1 broadcast and homogeneous LIF parameters, not biological homogeneity.

## Real structural asymmetry under identical bilateral drive

The simulation graph retains these MaleCNS structural facts:

| DNp01 | Incoming edges | Incoming structural weight |
| --- | ---: | ---: |
| 10001 | 146 | 4,800 contacts |
| 10010 | 165 | 6,424 contacts |

For the reference combined run, body 10001 received 512 delivered events with
summed model increment 99.60 `mV_eq`; its peak filtered state was 22.069969
`mV_eq`. Body 10010 received 614 events with summed model increment 139.88
`mV_eq`; its peak filtered state was 30.111573 `mV_eq`. The stronger direct
structural input reaches threshold earlier and more often in this selected
linear-coupling model.

This is a connectome-derived difference propagated through the explicit rule
`event_increment = k_syn * structural_weight`. It does not demonstrate that
contact count equals physiological efficacy or explain every biological
left/right difference.

## Simulator-relative temporal chain

For the reference combined run at 0.1 ms:

```text
stimulus sampling starts                    0.0 ms
LC4 and LPLC2 encoder drive first nonzero  0.0 ms
first LC4 spike                            13.9 ms
first delivered visual -> DNp01 event      15.7 ms
first LPLC2 spike                          40.0 ms
DNp01 10010 first spike                    45.3 ms
DNp01 10001 first spike                    69.3 ms
```

The delivered-event offset is the configured 1.8 ms chemical-delay prior.
This chain starts at direct Level P drive, omits upstream biological visual
processing, and must not be compared directly with the approximately 19 ms
experimental stimulus-to-GF latency as though the quantities were equivalent.

## Timestep robustness

The reference trajectory and parameters were resampled and simulated at each
neural timestep. Exact replay passed independently at every timestep.

| dt (ms) | LC4 first / count | LPLC2 first / count | first event | 10001 first / count / peak V | 10010 first / count / peak V | Regime |
| ---: | --- | --- | ---: | --- | --- | --- |
| 0.05 | 13.90 / 756 | 39.95 / 370 | 15.70 | 69.20 / 1 / -45.001594 | 45.25 / 2 / -45.001646 | R4 |
| 0.10 | 13.90 / 756 | 40.00 / 370 | 15.70 | 69.30 / 1 / -45.027138 | 45.30 / 2 / -45.014568 | R4 |
| 0.20 | 14.00 / 756 | 40.00 / 370 | 15.80 | 69.40 / 1 / -45.054119 | 45.40 / 2 / -45.057400 | R4 |

Event counts remain 512 for body 10001 and 614 for body 10010; summed model
increments remain 99.60 and 139.88 `mV_eq`. Across 0.05–0.2 ms, the maximum
first-spike difference is 0.20 ms, the first-event difference is 0.10 ms, and
the maximum reported DNp01 peak-membrane difference is about 0.0558 mV. The
operating regime and spike/event counts are stable. Timing differences are
compatible with fixed-step sampling and end-of-step spike timestamps; they do
not provide sub-`dt` precision.

## Parameter effects and remaining identifiability limits

The one-at-a-time probes behave in the expected model direction:

- reducing `G_LC4` from 20 to 10 delayed its first population spike from 13.9
  to 42.9 ms and changed the combined result from R4 to R1; increasing it to
  40 advanced the first spike to 6.0 ms and increased repeated DNp01 spikes;
- reducing `G_LPLC2` from 20 to 10 left LPLC2 subthreshold; increasing it to
  40 advanced LPLC2's first spike from 40.0 to 13.9 ms;
- `omega_half` values 0.5, 1, and 2 shifted LC4's first spike to 11.2, 13.9,
  and 19.8 ms respectively;
- `theta_half` values 0.2, 0.4, and 0.8 changed LPLC2 spike totals to 740, 370,
  and 185 respectively;
- changing only `k_syn` from 0.001 to 0.005 to 0.01 left visual spike trains
  unchanged while scaling delivered increments and moving DNp01 from R1 to
  repeated-spike R4 regimes.

The E1 equations themselves admit gain/half-scale tradeoffs over a bounded
stimulus range: distinct pairs can produce similar drive traces. LIF
thresholding then discards subthreshold amplitude detail and can map different
drive traces to identical visual spike counts while retaining timing shifts.
At the next stage, delivered-event count loses information about drive
amplitude once presynaptic spike patterns coincide, while DNp01 filtering and
thresholding can further compress coupling differences.

Consequently neither encoder gains/scales nor `k_syn` is identifiable from
DNp01 first-spike time alone. Future evidence should first constrain LC4/LPLC2
feature-response time courses, then use pathway-isolated presynaptic timing and
DNp01 subthreshold telemetry to separate encoder parameters from coupling.
DNp01 spike timing should remain a validation observable, not the sole target.

## Limitations and safeguards

- There is no biological calibration, optimizer, or parameter fitting.
- There is no 19 ms latency fit or added visual-processing delay.
- Level C, body-specific visual-angle mapping, and receptive fields are absent.
- The active graph remains the 311 direct chemical visual-to-DNp01 edges, not
  the full 20,607-edge induced structural graph.
- `structural_weight` remains MaleCNS contact count; `k_syn` is a separate
  NeuroFly free parameter.
- Neither DNp01 receives direct external drive.
- Operating regimes are simulator descriptions, not behavior or escape.
- No stochasticity, plasticity, learning, motor output, or runtime renderer is
  introduced.
