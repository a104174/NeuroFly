# Phase 8P — TTMn→TTM neuromuscular evidence and parameter readiness

**Assessment:** `PASS`. The next bounded boundary is an **exploratory TTM neuromuscular-input receipt**, not a muscle response or activation state. The adult *Drosophila* experiments establish a real, history-dependent TTM NMJ and measured muscle electrical responses, but do not calibrate transfer from NeuroFly's model-derived output event to an exact MaleCNS body's NMJ, muscle state, or force. This phase changes documentation only.

The Phase 8K source separates `MALECNS_NEURAL_IDENTITY` (body `800146`, TTMn/R; body `804642`, TTMn/L) from `PRIMARY_LITERATURE_TARGET_EVIDENCE`. The 70/20 central chemical structural counts are metadata, never NMJ efficacy.

### Response, transmitter and reliability classifications

| Quantity | Classification | Safe interpretation |
| --- | --- | --- |
| TTM muscle potential after GF or thoracic stimulation | `MEASURED` | Electrical muscle endpoint; composite path for GF stimulation, subpath for thoracic motor stimulation. Neither is muscle force. |
| Intracellular TTM G1 evoked/miniature junction potentials | `MEASURED` at the fiber/preparation level; reported ~45 mV evoked G1 EJP and ~191 quanta are `DERIVED` estimates | The glutamate manipulation and quantal release support a chemical, glutamate-sensitive adult TTM NMJ; a specific receptor composition or exact-body transmitter assignment remains `UNRESOLVED` here. Do **not** import the **central** GF→TTMn cholinergic component. |
| TTM response during repeated stimulation | `MEASURED` under each study's frequency, temperature, genotype and recycling condition | Conditional response/following and depression; not a universal one-to-one reliability probability. Koenig–Ikeda 2007's 1 Hz no-depression condition does not negate faster depression in other trains. |
| NeuroFly event→TTM response, whole-muscle activation or force | `MODELLED` only if a future model explicitly defines it; currently `UNRESOLVED` | The Phase 8N event is not a demonstrated axonal action potential; Phase 8O dispatch is not a TTM electrical response. |

Thus a *real* TTMn action potential can drive an electrical TTM response in the tested preparations, but the empirical conditional reliability cannot be transferred as a probability for NeuroFly's uncalibrated event. A proposed one-event→one **NMJ-input receipt** is `PLAUSIBLE_BUT_UNCALIBRATED` as a software abstraction, not one-event→one successful release or muscle response.

## Timing decomposition

| Segment | What is observed; present status |
| --- | --- |
| A. Central GF→TTMn | Classic pathway work and central perturbations support a rapid mixed connection; Tanouye–Wyman's composite muscle timing does not isolate a MaleCNS pair-specific neural delay. |
| B. TTMn axonal conduction | Included between thoracic stimulation and TTM potential in Kadas et al.; not isolated for body 800146/804642. |
| C. TTMn→TTM synaptic transmission | Chemical vesicle release and G1 responses are observed by Koenig–Ikeda; **onset delay at the NMJ alone is not identified** by those reported values. |
| D. TTM electrical response | Muscle potential onset is the Tanouye–Wyman/Kadas timing endpoint; G1 intracellular junction potentials and depression are Koenig–Ikeda electrical quantities. |
| E. Mechanical contraction onset | Not identified by the reviewed electrical latency measures; cannot be inferred from them. |
| F. Leg extension/behavior | Downstream kinematic/behavioral endpoint, not a neuromuscular delay or muscle-state parameter. Out of scope. |

Kadas et al.'s direct TTMn-stimulation→TTM-potential interval **partially constrains the combined B+C+D subpath**. It is not an isolated C value; stimulation-to-axon activation location and muscle potential onset contribute. Tanouye–Wyman's GF→muscle interval additionally includes A and upstream conduction. Do not subtract unrelated experiments to invent C. **Isolated NMJ delay: `NOT_IDENTIFIABLE`** (not `SUPPORTED_EXACT`); the combined subpath is `PARTIALLY_CONSTRAINED`. The Phase 8N event is timestamped at its integer threshold-crossing model boundary, which is not known to coincide with an axon-terminal spike.

## Candidate next abstractions and claim budget

| Option | New free assumptions / parameters | Valid claim; decision |
| --- | --- | --- |
| A. TTM NMJ-input receipt only | One categorical rule: each *validated Phase 8N* output event yields one **exploratory input receipt** for its already-resolved Phase 8K TTM class association. Preserve identity/time as bookkeeping; **no biological zero-delay assertion**, release success or amplitude. | Useful beyond Phase 8O only if it marks a distinct **attempted neural→NMJ handoff**, with its own provenance and no conflation with target association. | B. Dimensionless activation integrator | Define state meaning, gain, decay/tau, initial state, event handling and optional saturation; choose handling of failed release/depression. All numeric values would be `MODEL_ASSUMPTION`s. | Could claim an *exploratory activation state responds* to model events, never biological contraction. Uncalibrated and premature relative to A. |
| C. Electrical muscle state | Choose G1 vs other fiber/whole TTM, resting value/units, membrane or EJP dynamics, event response, decay, saturation, repeated-response behavior, and observation bridge. | G1 electrical data are useful constraints for a **future fiber-specific** model, not a clean parameterization of NeuroFly's class-level TTM target. `NOT_READY` now. |
| D. Release/depression-aware NMJ | Define vesicle pool, docking/priming, quantal release, recovery, temperature/frequency/genotype context, and output observation. | Biologically relevant for repeated-stimulus response amplitude but over-complex for the first receipt-only vertical slice. |
| E. No additional interface | No assumptions. | Scientifically safe, but leaves no explicit, testable NMJ-input handoff; A can add that without pretending to model a response. |

History dependence is **not required to record an input receipt**, but the Koenig–Ikeda results make it necessary to address for any future model claiming valid **repeated-stimulus electrical response amplitude or efficacy**. Their preparation-specific release/recycling values must not silently become parameters of a whole-TTM state.

## Provenance and Phase 8Q boundary

Proposed (not implemented) ancestry: `SYNTHETIC_MOTOR_INTERFACE_TEST` DNp01 fixture → Phase 6C dimensionless TTMn state → Phase 8N `EXPLORATORY_MODEL_DERIVED_MOTOR_NEURON_OUTPUT` → Phase 8O literature-supported target dispatch → proposed `EXPLORATORY_NEUROMUSCULAR_INPUT` **receipt**. A later, separately justified `EXPLORATORY_MUSCLE_ACTIVATION_STATE` must be different. The receipt should preserve upstream event ID, target-association ID, body/type/qualified target side, integer boundary and all artifact/config hashes. Its copied timestamp is dispatch bookkeeping, not zero biological NMJ delay. Zero input yields zero receipts; one valid model event yields one class-level receipt. No DLMn input is authorized.

**Decisions:** next boundary `DEFINE_TTM_NMJ_EVENT_RECEIPT_INTERFACE`; parameter readiness `READY_FOR_EVENT_RECEIPT_ONLY`; delay `TTM_NMJ_DELAY_NOT_IDENTIFIABLE`; history `DEPRESSION_DEFERRED_BUT_REQUIRED_FOR_REPEATED_STIMULI`; muscle state `TTM_EVENT_RECEIPT_NO_STATE`.

**Exactly one bounded Phase 8Q:** implement and replay a provenance-explicit **TTMn-only NMJ-input receipt ledger** downstream of the pinned Phase 8O dispatch, accepting only validated Phase 8N model-derived output ancestry and Phase 8K TTM association. It must distinguish target resolution from an exploratory NMJ-input handoff, preserve qualified/unresolved targets and exact event identity/time, and test zero/single/bilateral/repeated fixtures. No release-success claim, measured delay, electrical potential, activation state, depression dynamics, force, behavior, DLMn model or production sensory adapter. If a receipt cannot be made semantically distinct from Phase 8O without implying transmission, Phase 8Q should fail closed rather than relabel the existing dispatch.
